## 3. 人工观看检查（评审指定的最低检查项）

打开 `final.mp4` 对照 `final.srt`、`materials/index.json`：

- [ ] **英语旁白**：自然、无漏读/错读/重复；逐段与 script.json 文本一致
- [ ] **画面匹配**：每段画面与该段旁白主题相符（对照 index.json 的
      query_used；如出现 fallback=true 的通用画面，说明已触发人工审核闸门，需逐段确认可接受）
- [ ] **字幕同步**：字幕与旁白对齐、无越界/残留；片尾完整不戛然而止
- [ ] **音量**：人声清晰、BGM 不压人声、无长时间无声
- [ ] **画面质量**：无长黑屏/损坏帧/明显重复镜头
- [ ] **封面**：cover.jpg 可用、与内容相符
- [ ] **上传包**：upload_info.txt 的标题/描述/署名（含作者与来源页）准确
